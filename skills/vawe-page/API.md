## Motion: `import { ... } from "../../core/motion/presets.js"`

- bands (s): energy 0.15-0.3 (mid 0.225), professional 0.3-0.5 (mid 0.4), gravity 0.5-0.8 (mid 0.65), cinematic 0.8-2 (mid 1.4). Default band: gravity.
- ease names for `ease:`, `EASE.<name>` (CSS linear()) and `easeFn(name)`: land [fling, hang], landSoft [20%@2.5, hang], settle [long, long], swap [hang, hang], glide [easyEase, 33%@0.1], carry [easyEase, fling], leave [easyEase, long], launch [easyEase, 25%@3], pop [fling, 35%@-1.5], nudge [fling, 35%@-0.8].
- enter(el, { at, band | duration, from, scale, blur, ease, anticipate, vary }): from "0 0.5em", scale 0.96 to 1, ease land, 650 ms, the fade takes 260 ms; anticipate 0 to 0.2.
- leave(el, { at | end, entrance, to, blur, ease }): to "0 -0.3em", ease launch, 390 ms by default; 0.6 of the element's enter() when it has one.
- stagger(els, { at, gap, seed, nudgeEvery, ...enter opts }): the start times of 3 elements by default are 0, 0.0532, 0.0907; gaps 30 to 80 ms, the run fits 0.5 s.
- layer(main, secondary, { at, overlap, band, secondary: { ... } }): the secondary starts at 0.455 s in the next slower band (cinematic).
- keys(el, prop, [[t, value, handle?], ...]): an After Effects key table; a handle shapes both sides of a key, or `{ in, out }`; none is linear.
- camera(wrapper, { kind, at, band | duration, from, to, origin, strength, dir, travel, ease }): kind push 1 to 1.12, pull 1.15 to 1, drift 1 to 1.03 slide -1.5% -0.8%, whipOut, whipIn (travel in % of the frame); 1400 ms by default; one scale animation per wrapper at a time.
- parallax([[el, depth], ...], cameraOpts): camera() on each layer with `strength` = depth (1 is the camera, under 1 ground, over 1 front).
- ramp(outEl, inEl, { at, kind, duration, amount, inAmount, blur, fade, dir, origin }): out/in travel by kind scaleOut 0.3/0.4, scaleIn 0.3/0.4, x 40/60, y 40/60 (scale units; x and y in % of the frame), 0.45 s by default.
- focus(el, { at, blur, scale, opacity, ease, band | duration }): blur 10px, scale 1, opacity 1, ease settle, 1400 ms.
- Each verb has a pure `<verb>Specs` twin that returns the keyframes and timing without an element. Product UI timings: `UI` in `core/motion/ui.js`.
